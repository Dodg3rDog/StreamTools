# Purchased Overlays

Place paid or otherwise private overlay files here.

This folder is ignored by git so purchased overlay code and assets are not uploaded to GitHub.

Example:

```text
public/overlays/purchased/nutty-shoutout-overlay/
```

When StreamTools is running, local OBS browser sources can use URLs like:

```text
http://192.168.1.131:3030/overlays/purchased/nutty-shoutout-overlay/
```

Back up this folder separately from git.
