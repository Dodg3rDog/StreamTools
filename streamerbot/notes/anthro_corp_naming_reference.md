# Anthro-Corp Naming & Worldbuilding Reference

This file is a naming reference for Codex and future development work across the Anthro-Corp / Night Howlers stream universe. Use this when naming widgets, folders, files, UI labels, fictional departments, NPCs, commands, rewards, alerts, terminal modules, and lore-facing systems.

The goal is to keep project names, feature labels, and in-universe terminology consistent across stream overlays, widgets, web tools, Discord/community features, and lore-driven interactive experiences.

---

## 1. Core Brand / Universe Names

### Anthro-Corp
Primary fictional corporate entity.

Use for:
- In-universe systems
- Corporate UI themes
- Terminal interfaces
- Employee IDs
- Research divisions
- Stream overlays with a corporate/lab/experimental tone
- Widgets that feel like they are part of an internal corporate dashboard

Tone:
- Corporate
- Mysterious
- Slightly ominous
- Research-heavy
- Clean but unsettling
- Professional on the surface, strange underneath

Suggested formatting:
- `Anthro-Corp` for public-facing prose
- `ANTHRO-CORP` for terminal headings
- `AC` as shorthand in IDs, logs, and system prefixes

Examples:
- `Anthro-Corp Interactive Terminal`
- `Anthro-Corp Personnel Registry`
- `AC Research Division`
- `AC-OWN-WOL-0001`

---

### AnthroCorp
Compact variant.

Use when:
- A hyphen is awkward in code, filenames, variables, or IDs
- Naming internal packages or modules
- Creating repo-safe identifiers

Examples:
- `anthrocorp_terminal`
- `anthrocorp_registry`
- `AnthroCorpUserProfile`

Prefer `Anthro-Corp` in lore/prose and `anthrocorp` in code.

---

### Anthro-Corp Studios / AC Studios
Possible real-world-facing creator/business identity.

Use for:
- Commission storefront branding
- Creator business identity
- Art/service branding
- Less lore-heavy public-facing presentation

Tone:
- Creator-owned studio
- Professional
- Flexible enough for art, stream tools, commissions, and digital goods

Avoid making every practical tool too heavily in-universe if it needs to feel clear for customers.

## 4. Corporate / Division Naming

Anthro-Corp naming should feel like a mix of corporate bureaucracy, research containment, HR systems, and strange experimental departments.

### Existing / Discussed Division Code Pattern
Employee IDs use a format similar to:

```text
AC-<DIV>-<SPEC>-NNNN
```

Example:

```text
AC-OWN-WOL-0001
```

Where:
- `AC` = Anthro-Corp
- `DIV` = division code
- `SPEC` = species code
- `NNNN` = employee number

## 12. File / Folder Naming Conventions

For code, use lowercase kebab-case unless the environment requires otherwise.

Recommended:

```text
anthro-corp-terminal/
night-howlers-overlay/
rft-monitor/
clock-in-badge/
charge-pool-monitor/
time-guardian/
slot-machine-overlay/
sussy-spinner/
prompt-engine/
personnel-registry/
```

Avoid:

```text
Anthro Corp Terminal/
Night Howlers Overlay/
Sussy Spinner Final FINAL v2/
```

For JS variables, use camelCase:

```js
const employeeId = "AC-OWN-WOL-0001";
const divisionCode = "RFT";
const riftSyncStatus = "unstable";
```

For constants, use screaming snake case:

```js
const DEFAULT_DIVISION_CODE = "UNK";
const RIFT_STATUS_UNSTABLE = "unstable";
```

For CSS classes, use kebab-case:

```css
.employee-id-card {}
.rift-status-panel {}
.night-howlers-badge {}
```

## 20. Codex Guidance

When generating names for new files, folders, classes, IDs, or UI labels:

1. Prefer clear technical names for code and folders.
2. Use lore-rich labels only in the UI or lore-facing content.
3. Keep Anthro-Corp names corporate, clinical, and mysterious.
4. Keep Night Howlers names playful, nocturnal, pack-like, and community-focused.
5. Use Rift names for anomaly, portal, timeline, signal, glitch, or story progression systems.
6. Use `AC-<DIV>-<SPEC>-NNNN` for employee IDs.
7. Use 3-letter division and species codes where compact IDs are needed.
8. Avoid naming unrelated technical utilities with overly vague lore terms.
9. For adult/sussy themed stream features, prefer suggestive but stream-safe labels like `After Dark`, `Sussy Override`, `Night Shift`, or `Club Mode`.
10. When in doubt, choose a name that is both understandable as code and flavorful in the Anthro-Corp universe.
