# AnthroCorp - Stream Systems Overview

## Core Concept
- Stream = AnthroCorp workplace simulation
- Viewers = Employees
- Streamer = Overseer / Employee (in-world)
- Systems = Training modules, incidents, and events

---

## Employee System
- Each viewer becomes an employee on first chat (if follower)
- Badge appears on first message:
  - Twitch profile icon
  - Employee ID (AC-XXX-XXXX format)
  - Division
  - Status (Active)

- Trigger rules:
  - First message per session OR cooldown-based
  - Followers only

---

## Divisions
- Graphics Division (art/design focused)
- Research Division (lore/puzzles/RPG)
- Engineering Division (tech/system interaction)
- Security Division (moderation/authority)
- Night Howlers (hidden faction)

- Assignment methods:
  - Random (default)
  - Command-based (optional)
  - Quiz-based (future)

---

## Night Howlers (Faction Layer)
- Secret organization within AnthroCorp
- Associated with after-hours activity
- Primary gathering location: club environment
- Unlockable / not default

---

## Locations (Stream Layout States)
- Office (default)
  - Work environment
  - Evaluations, systems, structured gameplay

- Home
  - Relaxed environment
  - Story events, personal interactions

- Club / Entertainment District
  - Neon silhouette environment
  - RNG events, spotlight system, chaotic behavior

---

## Game Systems (Connected)
- Hangman → Code Break Protocol
- Trivia → Employee Evaluation
- RPG → Exploration Assignment System
- Slot Machine → Resource Allocation

- All systems:
  - Reward credits
  - Affect progression
  - Tie into employee profiles

---

## Progression System
- Tracks per viewer:
  - Credits (currency)
  - Inventory (future)
  - Division
  - Reputation
  - Behavior flags

---

## Behavior System
- Tracks actions:
  - Participation in events
  - Rule-breaking / chaotic actions
  - Positive contributions

- Effects:
  - Alters RNG outcomes
  - Unlocks unique events
  - Changes interactions
